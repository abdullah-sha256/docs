---
title: "Continue a conversation while you work"
description: "Recent conversations help you return to an earlier investigation."
---

The Gia side panel lets you work with a conversation alongside another Nini page.

<Tip>
**Example:** Open a Match, bring up Gia beside it, and ask a follow-up that names the Match and the issue you want explained.
</Tip>

<Info>
**Before you start:** Know which investigation you want to continue. If changing topics, start a new chat so the question is easy to distinguish from earlier work.
</Info>

## Step by step

1. Open Ask and find Recent conversations. Select the conversation you want; use Show more if the conversation is not in the first few displayed.
2. Read the earlier question and its date range before continuing. An older answer may describe an older data snapshot.
3. Write a follow-up in the same conversation when it concerns that investigation. Restate the period if it has changed.
4. From another page, use Toggle Gia to open the side panel. Enter the relevant record reference and your question; do not assume that simply opening a page supplies all of its context.
5. Use New chat when starting a separate topic. Use Toggle Gia again to close the panel and give the underlying page more room.

<Check>
**Expected result:** You can return to an earlier question or start a separate investigation without losing the page you are reviewing.
</Check>

<Warning>
**If you get stuck:** If an old conversation appears to disagree with today's screen, check its original scope and ask for a current review using the same dates and sources.
</Warning>
