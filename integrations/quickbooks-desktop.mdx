---
title: "Connect QuickBooks Desktop"
description: "QuickBooks Desktop uses a different connection path because its company file is on a Windows computer."
---

Nini's documented setup gives you a link to complete on the computer running QuickBooks Desktop.

<Tip>
**Example:** You review Nini in a browser on your laptop, but the bookkeeping company file is on an office Windows computer. Complete the Desktop connection on that computer.
</Tip>

<Info>
**Before you start:** Have access to the Windows machine running QuickBooks Desktop and someone who can authorize access to the correct company file. Confirm the organization in Nini first.
</Info>

## Step by step

1. Open Settings → Integrations → Add integration and find QuickBooks Desktop. Read About if you want to confirm that this is the Desktop connector.
2. Choose Connect. The documented flow provides a connection link and instructions for completing setup on your QuickBooks machine.
3. Open that link on the Windows computer running QuickBooks Desktop. If you started on another computer, use the copyable link to continue on the correct machine.
4. Follow the connector's instructions for the intended company file. Have the company administrator complete any required authorization. Use the setup instructions shown there for any required software.
5. Return to Nini and wait for the pending connection state to resolve. Confirm the displayed connection refers to the intended company.
6. Check sync status and inspect a representative invoice or bill in Nini against the source. Use [Check connection health and imported data](/integrations/connection-health) if the connection is present but data has not arrived.

<Check>
**Expected result:** The Desktop company is connected through its own setup route and a sample imported item has been checked.
</Check>

<Warning>
**If you get stuck:** If setup remains pending, confirm that it was completed on the correct Windows machine and company file. Ask the connection administrator to investigate; an Online connection is not a replacement for the Desktop setup.
</Warning>
