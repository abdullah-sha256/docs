---
title: "Find an uploaded or imported document"
description: "Documents holds original files and their review states."
---

Use it when you need to read an invoice, receipt or statement, or check what Nini extracted from it.

<Tip>
**Example:** You uploaded an August statement in September. Finding it may require checking both the upload timing and the document's own date.
</Tip>

<Info>
**Before you start:** Have part of the filename or an approximate date. Destination describes how Nini uses the file; review status describes where it is in the review process.
</Info>

## Step by step

1. Click Documents in the sidebar. Use Overview to see the summary of document work.
2. Click Browse to open the list of files.
3. Check Destination. Choose Reconciling for files used in matching or Analysis only for files intended for Gia's analysis.
4. Check the status filter. Needs Validation is the place to look for files awaiting review; also inspect Validated or Failed if the file is not there.
5. Check Dates and any other active filters. Find the file by its name and relevant date.
6. Open the file. Use Open full page when available to see the original beside the extracted records, then follow [Review information extracted from a document](/guides/documents/review-extracted-information).

<Check>
**Expected result:** You have found the original file and can inspect its extracted information.
</Check>

<Warning>
**If you get stuck:** If the file is missing, check the organization, Destination, dates and status first. If it is Failed, record the message shown. Avoid uploading another copy until you understand what happened.
</Warning>

<Note>
An Unreviewed row label or a Needs Validation filter is a review signal. It is not proof that the underlying amounts are wrong.
</Note>
